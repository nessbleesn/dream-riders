# Dream Riders landing

Статический лендинг для открытия новой экстрим-зоны Dream Riders / «Дрим Райдерс» в Парке Сказка.

## Структура

- `index.html` - структура страницы, тексты и блоки лендинга.
- `styles.css` - светлая/темная визуальная система, адаптив, фоновые эффекты, карточки аттракционов и анимированный подвал.
- `script.js` - переключение темы, сохранение темы, поведение шапки, reveal-эффекты и анимация цифр.
- `model.js` - Three.js-анимация трассы с движущимся вагончиком в футере.
- `assets/` - папка для логотипа, фото и видео.

## Уже добавлено

- `assets/skazka-logo.png` - исходный логотип.
- `assets/skazka-logo-cropped.png` - обрезанная версия для шапки.
- `assets/hero-video.mp4` - временное видео для первого экрана и медиаблока.
- `assets/hero-poster.jpg` - постер для видео.
- `assets/boomerang-wide.webp`, `assets/boomerang-loop.webp`, `assets/boomerang-track.webp` - временные оптимизированные фото Бумеранга.
- `assets/smerch-close.webp`, `assets/smerch-wide.webp` - фото аттракциона «Смерч».
- `assets/vortex-action.webp`, `assets/vortex-wide.webp` - фото аттракциона «Вихрь».
- `assets/og-dream-riders.jpg` - картинка для соцсетей.
- Переключатель светлой и темной темы в шапке.
- Видимый video-first hero без декоративных фигур поверх.
- Анимированные цифры 360 / 37 / 85,3 в первом экране.
- Новый акцент на открытии экстрим-зоны: «Вихрь», «Бумеранг» и «Смерч».
- Карточки аттракционов с ключевыми характеристиками: 36 км/ч, участок вниз головой, 360°, 37 м, 85,3 км/ч и 34 м.
- Обновленная дневная кинетическая подложка с трассовой графикой.
- Анимированный футер с движущейся Three.js-сценой.
