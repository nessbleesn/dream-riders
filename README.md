# Dream Riders landing

Статический лендинг для открытия аттракциона «Бумеранг» в Парке Сказка.

## Структура

- `index.html` - структура страницы и тексты.
- `styles.css` - светлая/темная визуальная система, адаптив, фоновые эффекты и плейсхолдеры.
- `script.js` - переключение темы, сохранение темы, поведение шапки и reveal-эффекты при скролле.
- `assets/` - папка для логотипа, фото и видео.

## Уже добавлено

- `assets/skazka-logo.png` - исходный логотип.
- `assets/skazka-logo-cropped.png` - обрезанная версия для шапки.
- Переключатель светлой и темной темы в шапке.
- Многослойная подложка: aurora-свет, шум, дуга трассы, speed-линии.

## Ассеты, которые ожидает каркас

- `assets/hero-video.mp4` - главное видео в первом экране.
- `assets/hero-poster.jpg` - постер для видео.
- `assets/og-dream-riders.jpg` - картинка для соцсетей.
- `assets/gallery-01.jpg`, `assets/gallery-02.jpg` - кадры галереи.
- `assets/poster.jpg` - афиша или ключевой визуал события.

## Что заменить перед публикацией

- Ссылку кнопки `Купить билет` в блоке `#tickets`.
- Цену, возрастные ограничения и точный формат открытия.
- Координаты и маршрут, если вход будет отличаться от основного адреса парка.
- Финальные формулировки FAQ после утверждения правил посещения.
